# Grundidee
Die Two-Pointer-Technik nutzt zwei Indizes (Zeiger), die gleichzeitig durch eine
Datenstruktur (Array oder Linked List navigieren). Anstatt in einer Schleife
alles mühsam mit jedem zu vergleichen, steuert man die Zeiger gezielt, um
unnötige Schritte zu überspringen.

# Warum ist das wichtig?
Ohne dieser Technik landet man oft bei einer Brute-Force-Lösung mit zwei
verschachtelten Schleifen (O(n²)). Two Pointer reduziert dies fast immer auf
O(n), da jeder Zeiger das Array höchstens einmal komplett durchläuft.
- In-Place: Man braucht oft keinen extra Speicher (O(1) Space), da man Elemente
  direkt im vorhandenen Array tauscht oder vergleicht.

# Die zwei Haupt-Stategien
1. Opposite Ends (Von außen nach innen)
Ein Zeiger startet links (0), der andere rechts (n-1). Sie bewegen sich
aufeinander zu, bis sie sich treffen.
- Einsatz: Prüfen auf Palindrome, Umdrehen von Arrays, oder das Finden von
  Zahlen, die eine bestimmte Summe ergeben (in einem sortierten Array).
- Logik: Wenn die Summe der beiden Pointer zu groß ist, bewege den rechten Zeiger
  nach links. Ist sie zu klein, bewege den linken nach rechts.

1. Slow & Fast Pointer
Beide Zeiger starten meist am selben Punkt, aber einer bewegt sich schneller
(z.B. zwei Schritte pro Durchgang) als der andere (ein Schritt).
- Einsatz: Finden von Zyklen in einer Linked List oder das Finden des exakten
  Mittelpunkts einer Liste ohne die Länge vorher zu kennen.
- Logik: Wenn der Fast Pointer den Slow Pointer überholt oder einholt, weiß man,
  dass ein Kreis (Loop) exestiert.

# Ablauf an einem Beispiel
Finde zwei Zahlen im sortierten Array `[1, 2, 4, 6, 8, 11]`, die zusammen 10
ergeben.
1. Start: `Left` auf 1, `Right` auf 11. Summe = 12.
2. Schritt: Wir brauchen eine kleinere Summe -> `Right` wandert nach Links.
3. Nächster Check: `Left` auf 1, `Right` auf 8. Summe = 9.
4. Schritt: Wir brauchen eine größere Summe -> `Left` wandert nach Rechts.
5. Nächster Check: `Left` auf 2, `Right` auf 8. Summe = 10. Richtig!

# Beispiel in Java
```java
public boolean isPalindrome(String s){
    int left = 0;
    int right = s.length() - 1;

    while (left < right){
        if (s.charAt(left) != s.charAt(right)){
            return false;
        }
        left ++;
        right--;
    }
    return true;
}
```
