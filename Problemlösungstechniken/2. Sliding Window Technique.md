# Grundidee
Die Sliding Window Technik wird verwendet, um effizient mit Teilbereichen
(Subarrays oder Substrings) einer Liste zu arbeiten. Anstatt für jeden Bereich
eine komplett neue Berechnung zu starten, "gleitet" ein Fenster über die Daten.
Dabei werden nur die Elemente betrachtet, die neu ins Fenster hineinkommen oder
verlassen.

# Warum ist das wichtig? (Effizient)
Ohne diese Technik nutzt man oft zwei verschachtelte Scheifen (ein O(n²)
Ansatz). Das führt bei großen Datenmengen zu einem "Time Limit Exceeded".
Mit dem Sliding Window reduzieren wir die Komplexität meist auf O(n), da jedes
Element im Idealfall nur zweimal angefasst wird: einmal beim "Hineinkommen"
und einmal beim "Herausgehen".

# Die zwei Arten von Fenstern
1. Fixed Window(Festes Fenster)
Die größe des Fensters `k` ist vorgegeben.
- Beispiel: "Finde die Summe jedes Teilbereichs der Länge 3."
- Logik: 1.Summe der ersten 3 Elemente berechnen. 2. Ein Feld weitergehen: Neues
  Element addieren, altes Element abziehen. 3. Das spart das erneute Addieren
  der mittleren Elemente.

2. Dynamic Window (Variables Fenster)
Die Größe des Fensters ändert sich je nach Bedingung.
- Beispiel: "Finde das kürzeste Teilstück, das in der Summe mindestens 100
  ergibt."
- Logik: 1. Rechts ausdehnen, bis die Summe 100 erreicht. 2. Links schrumpfen,
  um zu sehen, ob es auch mit weniger Elementen klappt.

# Ablauf an einem Beispiel
Aufgabe: Finde die maximale Summe eines Subarrays der Länge 3. Array:
`[2, 1, 5, 1, 3, 2]`
1. Erstes Fenster: `[2, 1, 5]` -> Summe = 8
2. Schieben: Zieh die `2` ab, füge die `1` hinzu. `[1, 5, 1]` -> Summe = 8−2+1=7
3. Schieben: Zieh die `1` ab, füge die `3` hinzu. `[5, 1, 3]` → Summe = 7−1+3=9
   (Neues Maximum!)
4. Schieben: Zieh die `5` ab, füge die `2` hinzu. `[1, 3, 2]` → Summe = 9−5+2=6
Ergebnis: 9

# Code-Beispiel (Java)
```java
public int findMaxSum(int[] arr, int k){
    int maxSum = 0;
    int windowSum = 0;

    for (int i = 0; i < k; i++){
        windowSum += arr[i];
    }
    maxSum = windowSum;

    for (int i = k; i < arr.length; i++){
        windowSum += arr[i] - arr[i - k];
        maxSum = Math.sum(maxSum, windowSum);
    }
    return maxSum;
}
```
