# Grundidee
Rekursion ist das Prinzip von "Selbstähnlichkeit". Anstatt eine Aufgabe in einem
Rutsch zu erledigen, delegiert die Funktion die Arbeit an eine Kopie von sich
selbst. Der Clou: Jede Kopie bearbeitet ein minimal kleineres Problem, bis das
Problem so winzig ist, dass die Lösung trivial (offensichtlich) ist.

# Warum ist das wichtig?
- Komplexe Strukturen: Viele Daten (wie Ordnerstrukturen oder Stammbäume) sind
  rekursiv aufgebaut. Mit Rekursion "fließt" dein Code naürlich durch diese
  Strukturen, statt sich mit kompliziertem Index-Management in Schleifen zu
  verheddern.

- Divide & Conquer: Rekursion ist das Herzstück der schnellsten Algorithmen der
  Welt (z.B. Quicksort oder Merge Sort). Sie spaltet ein Riesenproblem in zwei
  Hälften, bis nur noch Einzelergebnisse übrig bleiben.

- Der Preis: Rekursion ist nicht "gratis". Jeder Aufruf landet auf dem Call
  Stack (Stapelspeicher). Ist die Kette zu lang, kommt es zum Absturz
  (StackOverflow). Schleifen sind oft speichereffizienter, Rekursion ist oft
  eleganter.

# Die zwei Säulen der Rekursion
Jede rekursive Funktion steht auf zwei Beinen. Bricht eines weg, fällt das
Programm um:
1. Base Case (Der Anker) Ohne Anker treibt die Funktion unendlich weit ab. Der
   Base Case sagt: "Stopp, hier ist das Problem gelöst, wir kehren um!"
   Logik: Das kleinstmögliche Szenario (z. B. `n == 0` oder `liste.isEmpty()`).

2. Recursive Case (Der Abstieg) Hier ruft die Funktion sich selbst auf. Wichtig:
   Der übergebene Wert muss sich verändern, damit er sich dem Base Case
   annähert.
   Logik: "Ich löse einen kleinen Teil und den Rest erledigt mein
   'Zwillings-Aufruf' für mich."

# Ablauf an einem Beispiel: Die Fakultät (n!)
Berechne 3! (also 3 * 2 * 1).
1. Aufruf `fak(3)`: Ich weiß die Lösung nicht, aber sie ist 3 * fak(2).
2. Aufruf `fak(2)`: Ich weiß die Lösung nicht, aber sie ist 2 * fak(1).
3. Aufruf `fak(1)`: Ich bin der Base Case! Ich gebe `1` zurück.
4. Rückwelle:
   - `fak(2)` erhält die `1`, rechnet 2 * 1 und schickt 2 nach oben.
   - `fak(3)` erhält die `2`, rechnet 3 * 2 und schickt 6 als Ergebnis zurück.

# Beispiel in Java
```java
public int factorial(int n){
    // 1. Base Case: Der kleinste Stein der Pyramide
    if (n <= 1){
        return 1;
    }

    // 2. Recursive Case: Der Abstieg zum Base Case
    return n * factorial(n - 1);
}
```
