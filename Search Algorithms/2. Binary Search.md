# Was ist Binary Search?
Binary Search ist ein hocheffizienter Algorithmus, um ein Element in einem
sortierten Array zu finden. Er funktioniert, indem er den Suchbereich bei jedem
Schritt halbiert.

#### Die goldene Regel
Binary Search funktioniert NUR auf sortierten Daten! Wenn die Zahlen
durcheinander liegen, funktioniert die Logik des "Ausschließens" einer ganzen
Häfte nicht.

# Wie es funktioniert
Man sucht die Zahl 7 in einem Array von 1 bis 10.
1. Start: Der Suchraum ist das gesamte Array.
2. Mitte finden: Man schaut sich das Element in der Mitte an (z.B. die 5).
3. Vergleichen: Ist die 5 gleich der 7? Nein. Ist die 7 größer als die 5? Ja!
4. Eliminieren: Da das Array sortiert ist, wissen wir jetzt: Die 7 kann nicht in
   der linken Hälfte (1 bis 5) sein. Wir werfen diese Hälfte komplett weg.
5. Wiederholen: Wir suchen nur noch im Bereich 6 bis 10 weiter, bestimmen dort
   wieder die Mitte und halbieren erneut.
Das geht so lange, bis die Zahl gefunden wurde oder der Suchbereich eer ist.

# Effizienz: Warum O(log n)?
Die Zeitkomplexität von Binary Search ist O(log n).
- Bei 10 Elementen braucht man maximal 4 Schritte.
- Bei 1.000 Elementen maximal 10 Schritte.
- Bei 1.000.000 Elementen maximal 20 Schritte!

Selbst wenn die Datenmenge riesig wird, steigt der Rechenaufwand nur minimal an!

# Beispiel in Java

```java
public int binarySearch(int[] nums, int target){
    int left = 0;
    int right = nums.length - 1;

    while (left <= right){
        int mid = left + (right - left) / 2;

        if (nums[mid] == target){
            return mid;
        }

        if (nums[mid] < target){
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }
    return -1;
}
```

# Warum die Formel `left + (right - left) / 2`
In der Programmierung sieht man oft `(left + right) / 2`. In der Theorie ist es
das Gleiche, aber in der Programmierung kann die Summe von left + right so groß
werden, dass sie den Speicherbereich eines `int` sprengt (Integer Overflow). Die
längere Formel ist sicherer und wird deshalb bevorzugt.
