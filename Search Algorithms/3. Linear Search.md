# Was ist Linear Search?
Linear Search (auch Sequentiel Search genannt) ist der einfachste
Suchalgorithmus. Er geht eine Liste oder ein Array von vorne nach hinten durch
und prüft jedes einzelne Element, bis das Ziel gefunden wurde oder die Liste zu
Ende ist.

Die zwei großen Vorteile
1. Keine Voraussetzungen: Im Gegensatz zur Binären Suche muss die Liste nicht
   sortiert sein.
2. Einfachheit: Er ist extrem leicht zu programmieren und zu verstehen.

# Wie es funktioniert
Man sucht die Zahl 8 in diesem unsortierten Array `[3, 1, 4, 8, 2]`
1. Index 0: Ist 3 gleich 8? Nein.
2. Index 1: Ist 1 gleich 8? Nein.
3. Index 2: Ist 4 gleich 8? Nein.
4. Index 3: Ist 8 gleich 8? Ja! Suche beendet.

Wäre die 8 nicht im Array, hätte der Algorithmus alle 5 Elemente prüfen müssen,
um das sicher sagen zu können.

# Effizienz: Das O(n) Problem
Die Zeitkomplexität von Linear Search ist O(n). Das bedeutet, das der
Zeitaufwand mit der Datenmenge wächst.
- Best Case (O(1)): Das gesuchte Element ist direkt an der ersten Stelle.
- Worst Case (O(n)): Das Element ist ganz am Ende oder gar nicht vorhanden.

Bei einer Million Elementen braucht die Lineare Suche im schlimmsten Fall
1.000.000 Schritte. Die Binäre Suche nur 20. Das ist der Grund, warum man Linear
Search nur bei kleinen oder unsortierten Datenmengen nutzt.

# Beispiel mit Java
```java
public int linearSearch(int[] nums, int target){
    for (int i = 0; i < nums.length; i++){
        if (nums[i] == target){
            return i;
        }
    }
    return -1;
}
```
