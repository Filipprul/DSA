# Grundidee
Eine Hash Table ist eine Datenstruktur, die darauf ausgelegt ist, Informationen extrem schnell zu finden. Anstatt eine Liste von oben bis unten durchsuchen,
"errechnet" man sich den Speicherort direkt aus dem Suchbegriff (dem Key).

Man kann es sich wie ein Postfach-System vorstellen: Anstatt alle Briefe nach
dem Namen zu durchsuchen, hat jeder Name eine feste Nummer, die nach einer bestimmten Formel berechnet wurde.

# Der Prozess: Die Hash-Funktion
Die Hash-Funktion ist das Herzstück. Sie nimmt einen Schlüssel (z.B. eine Zahl oder ein Wort) und wandelt ihn in eine Zahl um - den Index.

Beispiel: Wir haben Zahlen als Schlüssel. Unsere Hash-Funktion nimmt einfach die Einerstelle der Zahl (Zahl mod 10).
1. Key:22 -> Einerstelle ist 2 -> Wert wird bei Index 2 gespeichert.
2. Key:45 -> Einerstelle ist 5 -> Wert wird bei Index 5 gespeichert.

# Das Problem: Kollisionen
Was passiert, wenn der Key 32 gespeichert werden soll? Die Funktion sagt: Einserstelle 2. Aber bei Index 2 liegt schon die 22! Das nennt man eine
Kollision.

## Lösungsmethoden für Kollisionen
1. Chaining (Verkettung): An jedem Index der Tabelle liegt eine kleine Liste.
   Wenn zwei Werte den gleichen Index haben, werden sie dort einfach hintereinandergehängt.
2. Open Addressing (Offene Adressierung): Wenn der Platz belegt ist, sucht der
   Algorithmus nach dem nächsten freien Platz in der Tabelle (z.B. einfach ein Feld weiter).

# Zeitkomplexität
Hier zeigt die Hash Table ihre Stärke:
- Avarage Case: O(1) -> Egal wie groß die Tabelle ist, man braucht meistens nur
  einen einzigen Rechenschritt, um den Wert zu finden.
- Worst Case: O(n) -> Wenn fast alle Schlüssel denselben Index haben (viele
  Kollisionen), degeneriert die Tabelle zu einer langsamen Liste.

# Code-Beispiel (Java)
In Java wird oft die `HashMap` genutzt. Hier ist ein Beispiel, wie man sie manuell für ein "Einerstellen"-Szenario nutzen würde:
```java
import java.util.HashMap;

public class HashBeispiel{
    public static void main(String[] args){
        HashMap<Integer, String> studenten = new HashMap<>();

        studenten.put(22, "Max");
        studenten.put(45, "Lisa");

        System.out.println("Wert bei Key: " + studenten.get(22));

        if(studenten.containsKey(45)){
            System.out.println("Lisa ist im System.");
        }
    }
}
```
