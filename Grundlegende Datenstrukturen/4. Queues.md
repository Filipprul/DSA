# Das Grundprinzip: FIFO (First-In, First-Out)
Das Element, das zuerst in die Schlange kommt, wird auch als Erstes wieder
herausgenommen. Es ist wie eine Warteschlange in einem Supermarkt an der Kasse:
Wer zuerst ansteht, wird zuerst bedient. Neue Kunden müssen sich hinten
anstellen.

# Die 3 Kern-Operationen
In Java (und den meisten Sprachen) arbeitet man mit diesen drei Hauptbefehlen:
1. Enqueue (Hinzufügen): Ein Element wird am hinteren Ende (Rear) der Schlange
   hinzugefügt.
2. Dequeue (Entfernen): Das Element am vorderen Ende (Front) wird entfernt und
   zurückgegeben.
3. Peek (Anschauen): Du schaust dir das vorderste Element an, ohne es aus der
   Schlange zu entfernen.

# Wo braucht man das in der Praxis?
Queues sind unverzichtbar, wenn Aufgaben nacheinander abgearbeitet werden
müssen, aber nicht sofort erledigt werden können:
- Drucker-Warteschlangen: Dokumente werden in der Reihenfolge gedruckt, in der
  sie gesendet wurden.
- Webserver-Anfragen: Wenn tausende Nutzer gleichzeitig auf eine Seite
  zugreifen, werden die Anfragen oft in einer Queue geparkt.
- Betriebssysteme: Task-Scheduling (welcher Prozess darf als nächstes die CPU
  nutzen).

# Queue in Java
In Java ist `Queue` ein Interface. Das bedeutet, du kannst nicht einfach
`new Queue()` schreiben. Die am häufigsten genutzten Implementierungen sind:
- `LinkedList`: Gut für einfache Queues.
- `ArrayDeque`: Oft schneller als die LinkedList.
- `PriorityQueue`: Eine Spezialform, bei der Elemente nicht nach Zeit, sondern
  nach Wichtigkeit (Priorität) sortiert werden.

# Beispiel in Java
1. LinkedList
```java
Queue<String> warteschlange = new LinkedList<>();
warteschlange.add("Kunde 1");   // Enqueue
warteschlange.add("Kunde 2");

String erster = warteschlange.poll();   // Dequeue
```

2. ArrayDeque
```java
Deque<String> kasse = new ArrayDeque<>();
kasse.addLast("Max");   // Enqueue
System.out.println(kasse.removeFirst());    // Dequeue
```
- Besonderheit: Man kann bei einer `Deque` an beiden Enden hinzufügen oder
  Entfernen.

1. PriorityQueue
```java
// Standardmäßig sortiert sie aufsteigend (kleinste Zahl zuerst)
PriorityQueue<Integer> hospital = new PriorityQueue<>();

hospital.add(10); // Leichte Wunde
hospital.add(1);  // KRITISCH
hospital.add(5);  // Mittelschwer

// Wer kommt zuerst dran?
System.out.println(hospital.poll()); // Output: 1 (Kritisch, obwohl später hinzugefügt)
System.out.println(hospital.poll()); // Output: 5
```
- Besonderheit: Unter der Haube nutzt die `PriorityQueue` einen Heap
  (eine Baumstruktur). Das Einfügen und Entfernen dauert O(logn).
