# Grundidee
Eine Linked List ist eine Datenstruktur, in der Daten in sogenannten Nodes
(Knoten) gespeichert werden. Ein Knoten besteht aus zwei Teilen:
1. Datenfeld: Der eigentliche Wert (z.B. eine Zahl oder ein Name).
2. Referenz (Link): Ein Zeiger, der auf den nächsten Knoten in der Kette
   verweist.
Das bedeutet, die Elemente liegen nicht direkt hintereinander im Speicher,
sondern sind über diese Links miteinander "verkettet".

# Die zwei Hauptarten
1. Singly Linked List (Einfach verkettet)
Jeder Knoten zeigt nur auf seinen nächsten Nachbarn. Der letzte Knoten zeigt auf `null`, was das Ende der Liste signalisiert.
- Vorteil: Verbraucht weniger Speicher.
- Nachteil: Man kann die Liste nur in eine Richtung (von vorne nach hinten)
  durchlaufen.

2. Doubly Linked List (Doppelt verkettet)
Jeder Knoten hat zwei Links: einen zum nächsten und einen zum vorherigen Knoten.
- Vorteil: Man kann die Liste in beide Richtungen durchwandern.
- Nachteil: Jeder Knoten braucht mehr Speicherplatz für den zuseätzlichen
  Zeiger.

# Beispiel in Java
1. Singly Linked List (Einfach verkettet)
```java
class SinglyNode {
    int data;
    SinglyNode next;

    public SinglyNode(int data) {
        this.data = data;
        this.next = null;
    }
}

SinglyNode head = new SinglyNode(10);
head.next = new SinglyNode(20);
head.next.next = new SinglyNode(30);

// Ergebnis: 10 -> 20 -> 30 -> null
```

2. Doubly Linked List (Doppelt verkettet)
```java
class DoublyNode {
    int data;
    DoublyNode next;
    DoublyNode prev;

    public DoublyNode(int data) {
        this.data = data;
        this.next = null;
        this.prev = null;
    }
}

DoublyNode first = new DoublyNode(10);
DoublyNode second = new DoublyNode(20);

first.next = second;
second.prev = first;

// Ergebnis: null <- 10 <-> 20 -> null
```
