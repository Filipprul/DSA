# Grundidee
Datenstrukturen sind verschiedene Arten, Informationen im Computer zu
organisieren. Jede Struktur hat eine spezielle "Form", die sie für bestimmte
Aufgaben schnell macht, während sie für andere Aufgaben eher ungeeignet ist.
Man wählt sie wie ein Werkzeug: Ein Hammer ist gut für Nägel, aber schlecht
zum Schrauben.

1. Das Array (Feld)
Ein Array ist eine feste Reihe von Speicherplätzen für den gleichen Datentyp.
- Analogie: Eine nummerierte Reihe von Schließfächern.
- Besonderheit: Man kann direkt über den Index (die Nummer) auf jedes Fach
  zugreifen.
- Nachteil: Die Größe ist statisch. Will man mehr Platz, muss man ein komplett
  neues, größeres Array anlegen.

2. Linked List (Verkettete Liste)
Hier hängen die Daten wie bei einer Kette hintereinander.
- Analogie: Eine Schnitzeljagd. Jeder Zettel (Knoten) sagt dir, wo der nächste
  Zettel liegt.
- Struktur: Besteht aus "Knoten" (Daten + Zeiger auf den nächsten Nachbarn).
- Vorteil: Dynamisch. Man kann überall einfach ein Glied einfügen.
- Nachteil: Langsamer Zugriff. Um zum Ende zu kommen, muss man die ganze Kette
  ablaufen.

3. Stack (Stapel)
Arbeitet nach dem LIFO-Prinzip (Last-In-First-Out).
- Ablauf: Das Element, das zuletzt "auf den Stapel" gelegt wurde, muss als
  Erstes wieder heruntergenommen werden.
- Einsatz: Rückgängig-Funktion (Strg+Z), Funktionsaufrufe.

4. Queue (Warteschlange)
Arbeitet nach dem FIFO-Prinzip (First-In-First-Out).
- Ablauf: Wer zuerst kommt, wird zuerst bedient. Neue Elemente stellen sich
  hinten an.
- Einsatz: Druckwarteschlangen, Kundensupport-Tickets.

5. Hash Table (Hashtabelle)
Speichert Daten in Schlüssel-Wert-Paaren (Key-Value).
- Ablauf: Ein "Hash-Algorithmus" berechnet aus dem Schlüssel
  (z. B. "Max Mustermann") sofort die Adresse im Speicher.
- Vorteil: Extrem schnell beim Suchen.
- Einsatz: Datenbanken, Wörterbücher.
