# Grundidee
Ein Array (auf Deutsch auch "Feld" genannt) ist eine Datenstruktur, die mehrere
Elemente des gleichen Datentyps in einer festen Reihenfolge speichert. Man kann
es sich wie eine Reihe von Schließfächern vorstellen, die alle direkt
nebeneinander in einer Wand verbaut sind.

# Die wichtigsten Merkmale
- Feste Größe: Ein Array wird meist mit einer bestimmten Anzahl an Plätzen
  erstellt. Wenn es voll ist, kann man nicht einfach ein neues Element
  "dazwischenquetschen".

- Gleicher Datentyp: In einem `int`-Array dürfen nur ganze Zahlen liegen, in
  einem `String`-Array nur Texte.

- Indizierung: Jedes Fach hat eine Nummer (den Index). Angefangen wird es mit
  der Zahl 0.

# Technische Einordnung: Der Speicherfaktor
Arrays sind deshalb so schnell, weil sie kontinuirlich im Arbeitsspeicher
liegen. Das bedeutet: Der Computer weiß genau, wo das erste Element liegt. Da er
weiß, wie groß ein Element ist, kann er die Adresse jedes anderen Elements
blitzschnell ausrechnen: Adresse = Startadresse + (Index * Größe eines Elements)
Deshalb hat der Zugriff auf ein Element (z.B. nums[5]) eine Zeitkomplexität von
O(1)-es geht sofort, egal wie groß das Array ist.

# Vor- und Nachteile
Vorteil:
- Schneller Zugriff: O(1) über den Index.
- Speichereffizient: Wenig "Overhead", da nur die Daten gespeichert werden.

Nachteil:
- Starrheit: Die Größe kann nach der Erstellung nicht mehr geändert werden.
- Teures Einfügen/Löschen: Willst du am Anfang etwas löschen, müssen alle
  anderen Elemente aufrücken (O(n)).

# Beispiel in Java
```java
// Ein Array deklarieren und füllen
int[] noten = {1, 2, 3, 4, 5};

// Zugriff auf das erste Element (Index 0)
int ersteNote = noten[0];   // Ergebnis: 1

// Die Länge des Arrays abfragen
int anzahl = noten.length;  // Ergebnis: 5
```
